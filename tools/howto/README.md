# 玩法影片（真實遊戲錄影＋字卡）

使用者 2026-11-21 要三支「特色玩法」影片，各約一分鐘，其中一支介紹超級化。橫式 1920×1080、30fps，沒有人聲。

## 做法
- `lib.mjs`：用 puppeteer 開本機的 `game.html`（4630 埠要先開），進頁面前把時間換成**虛擬時鐘**（`performance.now`、`requestAnimationFrame`、`setTimeout` 都換掉），每一格往前走 1/30 秒、畫完才截圖，所以不會掉格，也可以「走但不錄」來跳過敵人的回合。
- 字卡、手指點擊的圈、片頭片尾畫在疊在遊戲上面的一張畫布（`#ov`），跟著虛擬時鐘淡入淡出。教學便條（第一次遇到才出現的那種）全部當作看過，免得跟字卡疊在一起。
- 點擊是真的滑鼠事件（`page.mouse.click`），所以錄到的就是玩家會看到的反應。
- 聲音：`game.js` 的 `snd`／`playMusic` 在 `window.__sndLog` 存在時會記下每個音效的時間；收尾時把「有錄進去的那幾段」對到影片時間，寫成 `out/events.json` 交給 `tools/mix.py` 混音，配樂整支鋪一首戰鬥曲。
- 成品：`out/howto/上班旅人_玩法N_….mp4`（`out/` 不進 git）。

## 指令
```
node tools/howto/super.mjs      # ① 超級化
```
錄一支大約五分鐘。16GB 的機器一次只跑一支，不要同時跑別的瀏覽器測試。

## 為了節奏動的手腳（都是遊戲裡本來就會發生的狀態，只是不等）
- 超級化那支：開場把氣勢設成 86（打一下就滿）；每次變身完把氣勢補回 100，讓三個人接連變身。敵人的回合不錄。
