# 台灣風格 boss＋小兵（2026-11-20 使用者要求）

使用者原話：「我們要設計 boss 台灣風格 以及他的小兵 直接用現有的壞人改成台灣版本的奇幻敵人」。

做法：GPT 出三案（`ask1.txt` → `reply1.md` 全文），每案生一張模擬圖 `mock_1～3.png`（`gen.sh`，參考圖 `ref1～3.png` 是現有壞人拼起來的）。模擬圖只看氣氛和造型，定案後才照遊戲格式生逐格動作。

限制：不拿真實神明或宗教儀式當壞人（只借剪黏、宮燈、鞭炮這類美術元素），不放真實品牌、政治人物，笑的是職場行為。

| 案 | Boss | 場景 | 機制 | 小兵（原本 → 台灣版） |
|---|---|---|---|---|
| 1 剪黏甩鍋課長 | 甩鍋課長改成交趾陶剪黏戰將，黑鍋當盾、紅筆長槍 | 公司中庭變廟埕燈會，剪黏屋脊、宮燈、加班燈 | **這鍋你背**：蓄力時給一個我方角色掛「鍋」，大招只打他；他按防禦就把鍋彈回去，boss 暈一回合 | 社畜→燈彩值班兵、公文櫃→剪黏檔案衛、大媽→總務帳房姑、鸚鵡→傳話彩羽監工 |
| 2 不夜城營運總監 | 霓虹招牌斗篷、站在漂浮攤車王座、價目牌尖冠 | 高架橋下的夜市 | **加收服務費**：招式多扣 1 SP；全隊普攻打中他 3 次才熄掉招牌 | 社畜→夜市攤販兵、催稿信差→限時叫號使、實習生→續攤補給生、豬腦→業績金豬督導 |
| 3 鐵皮增建處長 | 坐在三層頂樓加蓋鐵皮機甲裡，鐵捲門盾、鋼梁槌 | 颱風天的頂樓加蓋會議室 | **再加一層就好**：蓄力一次疊一層（最多 3），被招式打中拆一層，大招看層數加傷 | 公文櫃→浪板檔案衛、臭臭阿北→煙霧巡樓伯、實習生→防颱留守生、催稿信差→逆風催件使 |

GPT 推薦案 1：黑鍋盾一眼看懂，成功彈鍋那一下本身就是笑點。

我的看法：
- 案 1 最好懂，也直接接上現有的甩鍋課長；但它是「課長換皮」，新鮮感最少。
- 案 3 畫面最震撼（會走路的頂樓加蓋），「颱風天照常上班」台灣人一看就懂，很適合當新地圖「台灣篇」的壓軸。
- 案 2 霓虹夜市最漂亮，但「服務費」機制要另外記普攻次數，對新手比較繞。
- 三案可以合成一條「台灣篇」路線：中段頭目案 1、菁英案 2、魔王案 3，小兵三套輪流出。
