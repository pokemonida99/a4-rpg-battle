三案分別走「廟埕燈彩」、「夜市霓虹」、「颱風鐵皮」路線。魔王都是濫用權力的職場主管；台灣元素放在建築、服裝和武器上。畫面維持正經奇幻 JRPG，笑點交給招式、台詞和行為。

## 方案一：剪黏甩鍋課長・萬責不沾身

### 1. Boss

**身分**  
把公司尾牙辦成個人登基大典的課長。自稱活動總指揮，成果全掛自己名下，出事就宣布「各組自行負責」。借用廟埕燈彩與剪黏美術，角色本身是公司主管。

**外型**

- 寬肩、圓腹，上半身像披甲將軍，下半身仍露出西裝褲與尖頭皮鞋。
- 暗紅西裝外披孔雀藍戰袍，肩甲由交趾陶與碎瓷剪黏構成，拼的是金幣、獎盃與向上箭頭。
- 背後立著兩面宮燈形旗幟，分別寫「本人督導」「下屬執行」。
- 左手抱巨大黑鍋盾，右手持紅筆長槍；鍋面映出被指定扛責任的人。
- 主色為暗紅、青綠、陶白與舊金，輪廓像一尊沉重華麗的陶甲戰將。

**機制：這鍋你背**

蓄力時，在一名我方角色頭上掛「責任鍋印」，下回合大招只攻擊他。若該角色使用**防禦**，便能擋下大部分傷害，並把鍋彈回去，讓 Boss 暈眩一回合。

只需要「標記＋檢查防禦＋暈眩」，玩家則要為被點名的人調整行動。

**招式名**

- 蓄力：**責任歸屬研議中**
- 普攻：**朱批穿心**
- 大招：**千錯萬錯，都是你的錯**
- 召喚：**各組派員支援一下**

**台詞**

- 登場：「今天這場我全權指揮。啊，有問題就找你們各組窗口。」
- 倒下：「我只是掛名召集人……怎麼連我也要寫檢討？」

### 2. 小兵

| 原本是誰 → 台灣版 | 外型怎麼改 | 保留機制 |
|---|---|---|
| 社畜小兵 → **燈彩值班兵** | 黑眼圈、鬆領帶與公事包保留；西裝外罩燈彩紋短甲，鋼筆變成紅纓筆槍，腰掛「工作人員」木牌。 | 普通步兵。 |
| 公文櫃重甲兵 → **剪黏檔案衛** | 公文櫃抽屜仍是盔甲主體，表面貼青綠陶片；櫃子盾包上屋脊剪黏，印章錘變成陶製巨印。 | 普攻傷害減半。 |
| 大媽同事 → **總務帳房姑** | 捲髮、老花眼鏡、袖套、帳本全保留；穿宮燈紋長背心，雞毛撢子綁彩帶，保溫瓶套上繡花布套。 | 招式傷害減半。 |
| 鸚鵡長官 → **傳話彩羽監工** | 鸚鵡頭與參謀大衣保留；大衣加上燈穗、彩瓷肩章，羽毛筆拖著長長的紅色批示紙。 | 照抄小兵行動；作為本戰較強的隨從。 |

### 3. 場景

公司中庭被搭成燈彩廟埕，剪黏屋脊下掛滿績效紅榜，遠處辦公樓的窗戶還亮著加班燈。

### 4. 放哪裡

**推薦取代「甩鍋課長」那一站。**  
黑鍋、責任轉嫁與反彈機制完全扣住原角色，適合做台灣篇第一個主題頭目，也能教玩家：被主管點名時，先學會保護自己。

## 方案二：不夜城營運總監・百攤抽成王

### 1. Boss

**身分**  
掌管公司「夜間創收專案」的營運總監。所有部門都得擺攤衝營收，他自己只負責抽成，還把員工休息區改成付費座位。諷刺的是層層收費的管理方式。

**外型**

- 細長身形踩著高底皮鞋，站在會漂浮的攤車王座上，視覺高度壓過全隊。
- 紫黑西裝披一件霓虹招牌斗篷，斗篷邊緣不停閃出「服務費」「管理費」「另計」。
- 頭戴由價目牌堆成的尖冠，胸前掛滿代幣與收款袋。
- 一手拿巨大找零盤作盾，一手揮動串著銅錢的計算機法杖。
- 主色為電紫、桃紅、青藍，搭配油亮黑鐵與暖黃燈泡；臉藏在招牌逆光裡。

**機制：本區加收服務費**

開場與每次大招後，Boss 掛出「服務費」狀態：**我方所有招式額外消耗 1 SP**。全隊累計以普攻命中 Boss 三次，就能打熄招牌，取消加價。

玩法是安排誰先用普攻拆掉加價，再讓主力出招；程式只需一個狀態與命中計數器。

**招式名**

- 蓄力：**優惠即將截止**
- 普攻：**找零盤飛斬**
- 大招：**全場買單，主管免單**
- 召喚：**人潮來了，全員加班**

**台詞**

- 登場：「我們這邊沒有強迫消費啦，基本業績每人一份。」
- 倒下：「營收明明有達標……你們怎麼還在算時薪？」

### 2. 小兵

| 原本是誰 → 台灣版 | 外型怎麼改 | 保留機制 |
|---|---|---|
| 催稿信差 → **限時叫號使** | 插羽毛的鴨舌帽、郵差包和背上鬧鐘都保留；披反光短斗篷，捲軸改成拖地的叫號單，鞋底帶青色疾風。 | 高速度，命中扣 SP。 |
| 續命實習生 → **續攤補給生** | 仍穿過大西裝，背著一箱無品牌綠色提神飲料；紙箱外加冰桶鐵框，瓶口冒出翠綠魔力。 | 替敵方補血。 |
| 豬腦長官 → **業績金豬督導** | 豬頭、勳章與獎盃戰鎚保留；改穿金線西裝，肩掛「本日冠軍」燈牌，獎盃裡堆滿代幣。 | 底氣越滿，大招越痛；作為本戰菁英隨從。 |

### 3. 場景

高架橋下的夜市一路延伸進黑暗，漂浮招牌層層疊起，最深處的巨型攤車亮著「全年無休」。

### 4. 放哪裡

**推薦當台灣篇中後段魔王，放在最終主管之前。**  
它能讓玩家重新思考 SP 與普攻的分配，也把「每個系統都要抽一手」做成直接可感受的戰鬥壓力。若原本奧客總經理已有重要劇情，這隻可作為他的營運主管。

## 方案三：鐵皮增建處長・風雨照常上班

### 1. Boss

**身分**  
靠「充分利用空間」升官的行政處長。把辦公室一路加蓋到雲裡，颱風來了仍堅持照常開會，理由是「頂樓還有位子」。

**外型**

- 矮壯的處長坐在一座鐵皮外骨骼裡，整體像會走路的三層加蓋辦公樓。
- 本人穿皺西裝、黃色雨衣，領帶被強風吹得水平飛起，臉上始終掛著視訊會議式微笑。
- 外骨骼用浪板、水塔、冷氣架與鏽蝕鋼梁組成；胸口是一扇透出日光燈的辦公室鋁窗。
- 左臂是鐵捲門巨盾，右臂是綁著會議麥克風的鋼梁槌。
- 主色為鏽紅、鐵灰、雨衣黃，關節漏出冷白燈光；每次蓄力，頭上就多疊一層鐵皮屋。

**機制：再加一層就好**

蓄力時增加一層「加蓋」，最多三層。**每次受到我方招式命中，拆掉一層**；普攻無法拆除。

大招依剩餘層數增加傷害，施放後層數歸零。玩家必須保留 SP，在他堆高時拆屋；多段招式每次施放只拆一層，方便平衡。

**招式名**

- 蓄力：**上面其實還有空間**
- 普攻：**鋼梁點名**
- 大招：**風雨無阻，全員到齊**
- 召喚：**附近同仁先來一下**

**台詞**

- 登場：「外面風大而已，公司裡面很安全。頂樓那幾位有聽到嗎？」
- 倒下：「只是鐵皮掉了……會議連結應該還能用吧……」

### 2. 小兵

| 原本是誰 → 台灣版 | 外型怎麼改 | 保留機制 |
|---|---|---|
| 公文櫃重甲兵 → **浪板檔案衛** | 抽屜盔甲與把手清楚露在外面，外加鏽紅浪板護肩；櫃子盾綁防水布，印章錘包著黃色膠帶。 | 普攻傷害減半，與 Boss 的拆屋需求一起鼓勵使用招式。 |
| 臭臭阿北 → **煙霧巡樓伯** | 駝背、拐杖、拖鞋配襪、歪菸與腰間鍵盤保留；披破雨衣，拐杖頂端綁小風向袋，煙霧在雨中形成灰色怪手。 | 命中者下次普攻傷害減半。 |
| 續命實習生 → **防颱留守生** | 過大西裝外套透明雨衣，背上的綠色提神飲料箱加了防水罩，胸前貼著被雨泡皺的值班表。 | 替敵方補血。 |
| 催稿信差 → **逆風催件使** | 羽毛鴨舌帽用繩子綁住，鬧鐘背包加鐵框，郵差包塞滿防水捲軸；短斗篷被風吹成尖翼。 | 高速度，命中扣 SP，干擾玩家留 SP 拆屋。 |

### 3. 場景

暴雨中的頂樓加蓋會議室，水塔與冷氣室外機懸在半空，腳下能看見整座城市被風吹斜的招牌。

### 4. 放哪裡

**推薦當新地圖「台灣篇」的壓軸魔王。**  
從公司一樓一路打到頂樓，最後對上把辦公室蓋進暴風裡的主管，地圖推進與魔王造型能形成完整收尾；「再加一層」也很適合表現永遠加碼的工作要求。

|---|---|---|---|---|

| 不夜城營運總監 | 霓虹斗篷、攤車王座、價目牌尖冠 | 業績你扛，抽成他拿 | 用三次普攻取消 SP 加價 | 台灣篇中後段 |
| 鐵皮增建處長 | 鐵皮樓巨甲、水塔、暴風雨 | 工作一直加，風雨也要到 | 留 SP，用招式拆除加蓋 | 台灣篇壓軸 |

**最推薦「剪黏甩鍋課長」。**  
黑鍋盾能讓玩家一眼看懂角色，剪黏陶甲又能把台灣特色做進魔王輪廓。機制只靠標記、防禦和暈眩就能成立，而且成功反制的那一刻，玩法本身就在講笑話：**這次終於讓主管自己背鍋。**
