## A. 現版問題

- **有效內容只有約 600px 寬**，隊伍、道具、強化、名冊互相壓縮。
- **字級依桌機觀看距離設計**，13～18px 縮到手機後無法閱讀。
- **資訊優先序失衡**：空位框與次要名冊，占掉隊伍資訊需要的空間。
- **箭頭、頭像卡與返回鈕尺寸不一致**，手指操作容易誤觸。
- **強化只有圖示**，玩家必須記住每個圖示的意思。
- **道具看起來像能使用**，但實際只能查看，介面缺少清楚標示。

## E. 手機橫向操作

- **安全區：**上述內容左右至少留 64px，上下至少留 32px。實機若有瀏海或系統手勢區，依安全區額外內縮，避免再縮小整個 UI。
- **觸控尺寸：**以 96×96 為最低目標，間距至少 8px；主要隊伍列使用 128px 高。按下時立即顯示紙卡反白或黃銅框。
- **返回鈕：**固定右上 `(1584, 32, 272, 96)`，兩個分頁位置一致。戰鬥中只改文案為「回戰鬥」。
- **拇指位置：**右側頁籤與左側整列皆為大區域；排序屬低頻操作，可留在隊伍右緣。返回鈕採寬按鈕，避免小角落叉號。
- **對比：**奶油字放深木底，深墨字放米色紙；黃銅數字放深色襯底。不要讓細字直接壓在高對比木紋上。
- **實機驗收：**按你提供的 0.41 倍換算，28px 約為 11.5 CSS px，36px 約為 14.8 CSS px。因此 28px 只用於短標籤，名字、HP、SP、數量一律維持 36px 以上。
