# 系統改版 v0.51.0（2026-11-24 凌晨，使用者睡前交代）

使用者原話重點：
- 三選一「實在太不誘人」，裡面的選項要檢討、大量更新。
- 開局代理制度：「每次看了都覺得那就都不要代理好了」。
- 福利社跟地圖上的報帳處要有差異，「不然誰要去走地圖上的呢？例如半價」。
- 道具「想像力也太弱，要有攻擊跟輔助等等」。
- 跟 GPT 討論，做一個系統性的改版，然後檢討、執行、檢查。

## 討論
- 給 GPT 的現況與問題：`gpt_a_prompt.md`
- GPT 的完整提案（含 JSON 資料）：`gpt_a.md`

GPT 的主要判斷：問題不只是數字小，而是：
- 大部分選項只讓原本的操作變強一點。
- 職位先扣能力。
- 福利社隨時能買永久素質，讓額度有固定的最佳用途。

解法是讓四個系統互相扣在一起：
- 職位：開局給玩法。
- 三選一：在永久強化、隊伍成長、道具之間取捨。
- 福利社：方便但原價。
- 報帳處：值得繞路。

## 我照做的
- **過關三格不同類別**：永久強化、隊伍成長、道具包，第四張「都先不要」可以領額度。
  - 隊伍成長：指定某人某招升級，或主角學一招。
  - 頭目戰：兩位同事各升一招。
  - 選之前就看得到確切內容。
- **獎勵分級**：
  - 強化分普通、進階、核心。
  - 一般戰：普通八成、進階兩成。
  - 菁英：進階八成、核心兩成。
  - 頭目、魔王：保證一個核心。
  - 福委會：三個不同標籤的強化，最多一個核心。
  - 都不要能領的額度：一般 15、菁英 20、頭目 25、福委會 20。
- **10 個核心強化**（會改變打法的規則）：交叉會簽、輪班表、公假輪休、急件快遞、回收分類、茶水間接力、議程封存、小組共筆、午休守門員、火災演習。
- **退休 12 個沒存在感的舊強化**：不再出現，但舊存檔拿過的照樣有效。
  - 加菜金、在職進修、士氣大振、以牙還牙、準時開會、保溫怒氣瓶、午睡重力毯、超大馬克杯、抽屜零食庫、公用冰箱、倒數桌曆、手搖飲團購。
  - 道具類的功能移到道具包，學招移到隊伍成長。
- **職位**：
  - 8 個重做，另有固定的「一般職員」（開局 30 點＋一杯奶茶，沒有限制）。
  - 開局可以免費換一組，一次。
  - 限制改成改變操作，例如救火組長第一回合不能防禦、換人；專案窗口同一人不能連兩回合用同一招。
- **福利社**：
  - 只賣道具、原價。
  - 每站最多買兩件，便當每張地圖一個。
  - 每站另有兩款普通戰術道具到貨。
- **報帳處**分兩頁：
  - 道具頁：普通道具半價、三款稀有道具（兩成機會出特級的救援隨身碟）。
  - 強化與服務頁：進階強化 90、核心強化 150、特訓 45、換一格強化 20。
- **道具 18 種**：
  - 恢復：奶茶、咖啡、便當、OK 繃。
  - 攻擊：訂書機、美工刀、暖暖包、退熱貼、螢光筆、碳粉匣。
  - 防禦：泡棉膠帶、輕便雨衣、降噪耳塞。
  - 輔助：薄荷膏。
  - 干擾：散會通知、主管紅章。
  - 特殊：提神飲料、救援隨身碟。
  - 攻擊道具不吃使用者的攻擊力，但會算弱點、標記、理虧，所以補師或 SP 不夠的人也有事可做。

## 我改掉 GPT 的地方（取捨）
| GPT 建議 | 我的做法 | 原因 |
|---|---|---|
| 福利社取消素質＋1、內部調派 | 搬到報帳處，每次來限一次 | 這兩個是使用者 11/21 要的功能；搬到地圖商店正好讓報帳處更值得走，不用刪 |
| 核心最多兩個，第三個要換掉 | 先不設上限 | 換核心要另外做介面；核心本來就少見（頭目保證一個、菁英兩成），先觀察 |
| 套裝（同標籤三個）拿掉 | 保留 | 使用者沒嫌，拿掉要改結案報告與畫面；標籤改成福委會「三個不同標籤」 |
| 道具倉庫 12 件、每場只帶 6 件 | 沒做 | 要做進場前選道具的介面；先靠「福利社每站兩件」與價格控制數量 |
| 人資專員：招募後新人下一場必須先發 | 改成「名冊最多 5 人」 | 好懂、不用另外追蹤誰是新人 |
| 風控專員：前排沒人帶護盾就不能放奧義 | 改成「沒人帶護盾時奧義要多 10 氣勢」 | 自己的護盾在輪到自己時會歸零，模擬裡這個職位通關率比別人低 20～30%；改完和其他職位一樣 |
| 採購主任：報帳處強化格換成稀有道具包 | 只寫「報帳處不能買強化」 | 道具本來就打 75 折，效果一樣、少一種貨架 |
| 「曼秀雷敦」「蠻牛」 | 改叫「薄荷膏」「提神飲料」 | 不用真的品牌名 |
| 普通強化的數字往下修（加薪 12% 等） | 數字大多沒動 | 使用者嫌的是不誘人，不是太強；先不砍 |

## 檢討（做完之後看到的）
- **模擬**（`node tools/sim.mjs`，每種 40～60 次）：
  - 會想的打法仍然 82～100%，隨便打 28～78%，跟改版前差不多。
  - 九個職位用一般行程和台灣篇各跑一次，風控專員修改後已經不墊底。
- **模擬器的限制**：模擬器只會用奶茶、咖啡、便當，不會用攻擊和干擾道具；核心強化也只會照順序挑。所以新道具和核心對通關率的影響，還要靠人實際玩。
- **核心的強弱還沒調**，憑感覺：
  - 急件快遞、議程封存可能偏強。
  - 輪班表要名冊五人以上才會出現，可能很少看到。
- **道具包圖只畫第一件道具**：兩件道具的道具包，卡片上只看得到一張圖。
