- 室內景的家具照台灣篇的掛法會比人還大（一張圖撐滿 30 單位寬，畫面只看得到中間四成）。所以 `scene.js` 的 `setBackdrop` 多一個 `rep`（橫向鋪幾次），這五張用 2：整張構圖都看得到，家具比例才對；左右多出來的用鏡射接上，上面不夠的用圖最上面一行補。`game.js` 的 `BGSRC` 第四個值就是它。台灣篇、地獄分公司沒動（還是 1）。
- 火盆和它的暖光是大廳本來的燈，掛了背景還在；鏡像內戰是冷色背景配暖色火光，使用者還沒看過，覺得不搭再說。
