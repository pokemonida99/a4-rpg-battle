## 現在的問題

12 位全是同一個模板：帶兩隻小兵、小兵在場頭目無敵（`guard`）、每回合第一下甩給小兵（`pot`）、蓄力放大招（`cycle`＋`locks`），再各加一個小花樣。造型上，剪黏甩鍋課長是甩鍋課長換裝，永續加班總監是奧客總經理加角。

## 新的共同規則

- 拿掉「小兵在場就無敵」和「甩給小兵」。每位頭目只留**一個自己獨有的規則**。
- **使用者 11/22 補充：「謎題也不要太麻煩」**。所以第二版每位都收成「一句話的規則＋一個對應的做法」，畫面上只多一個圖示或一個數字，不用記帳、不用同時顧兩件事。第一版比較複雜的（派工、打考績、矛盾要求、六片護甲、營業額加減、疲勞層數、服務對象）都換掉或砍半，原案留在 `ask1.txt`、`reply1.md`。
- 留著玩家已經會的：底氣歸零就理虧、大招前會預告、屬性與弱點。
- 每場帶三隻小兵，第三隻是輔助（見最後）。

## 參考：《歧路旅人》的頭目怎麼做（使用者 11/22：「看看歧路旅人會有什麼設定」）

查了一代、二代和手機版的攻略。它的頭目戰核心是「先解護盾的謎題，再比傷害」：每位頭目在同一套破防系統上只加**一個**小變化，規則都很短。常見的幾種：

| 歧路旅人的做法 | 例子 | 我們這邊對應誰 |
|---|---|---|
| 小怪在場時，頭目的弱點被鎖住，打倒小怪才解鎖（不是無敵，是打了不算破防） | 二代 Arcanette、La'mani；手機版盜賊長吉梅爾 | 第 10 位門禁人資長（第三版改成這個） |
| 弱點會換：每回合結束或每次從破防恢復後換一組 | 二代 Dolcinaea；手機版帕蒂斯三世 | 第 3 位猴子長官（第三版改成這個） |
| 破防後恢復，護盾變厚 | Herminia | 沒用，留著備案（鐵皮增建處長） |
| 後半段一回合連續行動好幾次 | 二代 Veronica | 沒用，留著備案（永續加班總監） |
| 蓄力預告大招，要在放出來前破防 | 很多頭目 | 我們本來就有；第 11 位檔案室主任的存檔讀檔就是這個的變化 |
| 抓走我方一人 | 二代 Dolcinaea 第二形態 | 沒用（比較麻煩） |
| 扣我方的行動資源 | 手機版艾德拉斯士兵扣 BP | 第 4 位考績魔導士扣氣勢 |

結論：第二版的方向跟它一致（一位一條短規則，都掛在「底氣／理虧／弱點」上）。第三版只換兩位，改成更貼近歧路旅人、也更貼角色的版本：猴子長官「一直改需求＝換弱點」，門禁人資長「門禁＝警衛鎖住弱點」。學的是做法，不照抄它的畫面和數值。

## 第一批做完的樣子（2026-11-22 晚，v0.48.0，使用者 11/22「好，都可以」之後做的；還沒上線）

一般行程六位＋茶水間補給員。跟上面第三版不一樣的地方：

- **多一條共同規則：底氣要打中弱點才削得動**（`rules.js` 的 `FIRM`、`L.firm`）。原因：拿掉小兵護衛之後，實機試打發現四個人輪流普攻就能讓頭目每回合理虧、完全不出手，新機制根本沒機會出現。學歧路旅人「先找弱點才破得了防」。招式自己寫明多削底氣的照算。**這一條沒先問使用者**，做完才回報。
- 甩鍋課長：鍋在蓄力時才掛出來（不是每回合）；背鍋的人被大招打是 2 倍傷害。
- 豬腦長官：搶功的加成放完大招就歸零。
- 輔助小兵：打氣是「頭目下一次攻擊 ＋30%」，用掉就沒了；沒人受傷就打氣、頭目已經被打過氣就補血、都不用就自己打一下（很弱）。站在頭目左後方（總經理個子大會擋住，那一場站右後方）。
- 血量：六位都比原本多 4～6%（少了護衛，多一點血）。

圖：`art/raw/jobs25.sh` → `art/raw/b2_*.png` → `tools/cut.py`（每位的 `--cell` 不一樣，寫在 README 的 v0.48.0 那一段）→ `art/enemy/`。舊的總經理六格揮擊圖（`anim/boss_1～6`）和 `boss_stun.png` 刪掉了，新造型用蓄力、出手兩張頂著。

檢查：`tools/tests/villtest.mjs`（六個機制＋輔助小兵＋底氣規則，共 49 項）；實機 `scratchpad/b2play.mjs` 六場各打到結束，沒有錯誤。

通關率（`node tools/sim.mjs`，一般行程）：會想的打法 100%／100%（跟原本一樣），隨便打 85%／69%（原本 98%／89%）。隨便打的那種不看弱點、不理新機制，所以掉最多。
