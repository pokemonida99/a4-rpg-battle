# 第四步：靜態圖審查（2026-11-24，只看不改）

規則：`08-pixel-craft.md` 的 C 節。檢查腳本 `tools/pixcheck.py`（只看、不改），數字表在 `04-check.md`。
對照圖 `04-sheet.png` 是實際大小（1×），每張旁邊放左右翻轉版，給人看對稱和臉。

```
uv run --with pillow --with numpy python tools/pixcheck.py [圖或資料夾] --md 報告.md --sheet 對照圖.png
```

沒給檔案就檢查 58 張：同事站姿 `art/chars/*_ready.png`、敵人待機 `art/enemy/*_idle.png`。

## 【程】程式檢查的結果
| 項目 | 規則 | 結果 | 判斷 |
|---|---|---|---|
| C1 顏色數 | 固定調色盤，有上限（約 64） | **每張 1,600～22,000 種**，58 張全部超過 | GPT 生的是「看起來像像素」的插畫縮小，不是限色像素畫；雜色是縮小時混出來的 |
| C2 明暗階數 | 一個色塊 3～5 階 | 先合成 32 色再算：**多數 6～14 階** | 階數太多，近看糊、縮小後顆粒感不夠 |
| C3 相鄰階差 | 縮小後要分得出來 | 合成後常常只差 4（明度 0～100） | 跟 C2 同一個原因 |
| C4 陰影只加黑 | 陰影要換色相 | 大部分 0%，少數 17～33%（阿強、小燕、幾個小兵） | **大致合格**：GPT 的陰影本來就有偏色 |
| C5 高彩度純色 | 整體沉穩 | 幾乎 0～4%；鸚鵡長官 10% | 合格；鸚鵡是故意的鮮豔 |
| C10 外框統一 | 整張同一套外框 | 多數 85～100% 是深色外框；小蝶 61%、Vivi 73%、阿傑 78% | 小蝶、Vivi 是淺色衣服用有色外框，**不算錯**（C11 反而建議有色外框） |
| C15 臉太暗 | 鼻子嘴巴不可接近黑色 | 數字不可靠（眼睛、頭髮也算進去） | 改成看 `04-sheet.png`；眼睛偏黑是遊戲畫風，嘴巴沒看到接近黑色的 |
| C17 完全對稱 | 鏡像要破壞對稱 | 全部 5～26% | 合格：沒有一張是複製鏡像 |
| C21 尺寸 | 100～200px 以內 | 奧客總經理 284×263、鐵皮處長 200×201 | 兩位最大的頭目超過，是刻意做大；先不動 |
| C22／C23 實際大小、不平滑放大 | 整數倍、nearest | 遊戲用 NearestFilter，沒有半透明像素 | 合格 |

## 試做：限色（不花額度，沒套進遊戲）
`tools/palq.py <代號> [顏色數]`：一個角色的所有圖（站姿、出招 8 格、軌跡格）共用一組 32 色調色盤、不抖色，輸出到 `out/palq/`，不覆蓋原圖。

試了小葵、阿傑：
- **外觀**：實際大小幾乎看不出差別，裙子花紋少一點細節。
- **抖動**：本來期待同一個部位每格都用同樣幾個顏色，停住的格子就不會閃，結果沒有改善：

| | 第 2→3 格 | 第 3→4 格 | 第 6→7 格 |
|---|---|---|---|
| 小葵原圖 | 90% | 76% | 65% |
| 小葵 32 色 | 89% | 77% | 64% |
| 阿傑原圖 | 73% | 84% | 71% |
| 阿傑 32 色 | 73% | 84% | 69% |

（數字是對齊腳底後，顏色差超過 24 的像素比例）

**結論**：抖動的原因是 GPT 每格都把形狀重畫一次，不是顏色雜訊。限色只是讓數字符合 C1～C3，畫面沒有明顯變好，所以先不套。

真要解決，要換做法：
- 先定一張基準圖，其他格只改有動的部位（手臂、武器），身體沿用同一張，像でんちゃん說的「部件分層」。
- 或叫 GPT 一次生同一張圖裡的 8 格，讓身體一致（之前的經驗：一張圖 8 格，形狀比分開生穩）。

## 【半】【人】要人看的
`04-sheet.png` 每個角色左邊是原圖、右邊是翻轉：
- C6 光源方向：GPT 圖大多是左上光，沒看到明顯反的。
- C11 有色外框：目前大多是黑外框。改成有色外框要重畫，先列著。
- C14 眼睛：遊戲的畫風是黑眼珠大亮點，這是畫風決定，不算錯。
- C16 手：先前的體檢列過「生完圖要放大數手指」，之後每批照做。
- C19 剪影：第一步列過 Kevin 躲在盾後面、阿傑第 2 格看不懂、小蝶道具前後不一致。

## 建議（等使用者選）
1. **不做限色**（這次的試驗說明效果不大）。
2. **下次重畫動作時改成「同一張圖生全部格子」或「身體沿用、只改動的部位」**，這才是解決抖動的方法，寫進第五步的提示詞規則。
3. 想要更像職業像素畫的質感（有色外框、少階明暗），要在生圖提示詞裡寫明，也寫進第五步。
